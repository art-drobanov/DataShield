# DataShield

[English](README.md) | **Русский**

**DataShield** — кодек прямой коррекции ошибок (FEC) для передачи небольших файлов через ненадёжные
каналы: текстовые пасты, мессенджеры, тела писем, радиоэфир, носители с повреждениями.

Файл превращается в поток маленьких самодостаточных пакетов — 75 байт, в текстовом режиме
ровно 100 символов Base64, одна строка = один пакет. Приёмник восстанавливает файл из
произвольно повреждённого, переставленного, дублированного и многофайлового потока —
результат гарантированно бит-в-бит исходному (проверка SHA-256 из заголовка).

## Возможности

- **Потери** — стирающий код Рида–Соломона над GF(2^16): при ECC 10% файл восстанавливается
  при потере до 10% секторов (процент настраивается).
- **Произвольный порядок** — накопительный приём без порядка; сектор несёт только свой номер.
- **Повторы** — повторные копии пакетов не вредят, а повышают счётчики подтверждений.
- **Шум** — пакеты опознаются сканированием скользящим окном; ни один байт не считается
  мусором, пока не проверен усечённым SHA-256.
- **Многофайловые потоки** — сектор криптографически привязан к своему заголовку через хеш;
  файлы не перепутываются.
- **Подделки и коллизии** — версии payload со счётчиками подтверждений и перебор комбинаций
  при сборке; исход без совпадения SHA-256 никогда не выдаётся.
- **Тихие повреждения** — сектор формально валиден, а файл не собирается: перебор подмножеств
  томов восстанавливает подозрительные по оставшимся и ECC.
- **Два формата вывода** — текстовый (Base64, для чатов и писем) и двоичный (сырые пакеты).
